# Şube Personel Maaş Programı (Taslak)

Web araştırmasına göre basit, pratik bir şube maaş sistemi taslağı.

## Özellikler (v1)

- Personel kartı (ad, pozisyon, şube, brüt maaş)
- Aylık hesap: çalışılan gün, fazla mesai, prim/bahşiş, avans
- Otomatik net maaş (SGK %14 + işsizlik %1 + gelir vergisi + damga)
- Şube bazlı özet (toplam brüt / net / maliyet)
- Excel / PDF çıktı (ileride)

## Dosyalar

- `index.html` → Basit web arayüzü
- `data.json` → Örnek personel ve şube verisi

## Kullanım

1. `index.html` dosyasını tarayıcıda aç
2. Personel ekle / düzenle
3. Aylık hesap yap
4. Şube özetini gör

Patrona gösterip detay isteğini netleştir, sonra geliştiririz.
